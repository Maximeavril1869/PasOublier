# PasOublier

Petite app (PWA) pour iPhone qui liste ce qu'il ne faut pas oublier au quotidien : éteindre les lumières, baisser les radiateurs, fermer les fenêtres…

Tout reste **en local sur le téléphone** (aucun serveur, aucun compte, aucune donnée envoyée).

## Fonctions

- **Checklists par moment** : « Avant de partir de la maison », « Avant de dormir », « Avant de quitter le travail » (modifiables, on peut en créer d'autres).
- **Tri manuel** : flèches ↑ ↓ dans Réglages pour ordonner les tâches de chaque moment et les moments eux-mêmes.
- **Remise à zéro chaque jour** : les cases se décochent d'elles-mêmes le lendemain.
- **Saisonnalité** : une tâche peut n'apparaître que sur certains mois (ex. radiateurs de novembre à mars).
- **« Pas concerné »** : pour une tâche qui ne s'applique pas ce jour-là, sans fausser les statistiques.
- **Historique** : ce qui a été oublié sur 30 jours, tâches les plus oubliées, série de jours sans oubli.
- **Sauvegarde / restauration** par copier-coller (les données vivent dans le navigateur de l'iPhone).
- Fonctionne **hors ligne**.
- Pas d'alertes : on ouvre l'app soi-même au moment clé.

## Installation sur iPhone

1. Ouvrir l'adresse GitHub Pages du projet dans Safari : `https://maximeavril1869.github.io/PasOublier/`
2. Bouton Partager, puis « Sur l'écran d'accueil ».
